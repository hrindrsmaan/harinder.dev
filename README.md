# Personal Portfolio

A modern personal portfolio built with React, TypeScript, and Vite.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- React 19 + TypeScript
- Vite (Fast HMR & build)
- Tailwind CSS v4 + [shadcn/ui](https://ui.shadcn.com) (Radix primitives)
- ESLint with TypeScript rules

UI components come from the shadcn CLI (`npx shadcn@latest add <name>`) into
`src/components/ui/`; design tokens live in `src/styles/globals.css`.

## 🔧 Scripts

- `npm run dev` - Development server
- `npm run build` - Production build
